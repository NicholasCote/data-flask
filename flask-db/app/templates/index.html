Persistent storage for stateful workloads on Kubernetes

A demonstration application backed by PostgreSQL on a Kubernetes PersistentVolume. Create notes, refresh, restart pods — your data persists.

About this demo

Notes are written to a PostgreSQL pod with a PersistentVolumeClaim. Use Initialize Database on first run to create the schema.
